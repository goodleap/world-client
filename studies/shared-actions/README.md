# 共享经营动作

`hammer.py` 按 `hammer-motion-plan.json` 给兼容的基础人物骨架添加 `Hammer`，由农民制作脚本调用。
基础人物目录、骨架绑定、身体和已有 Walk／Run 均不写回或重做。
后续角色可以导入同一动作生成器；运行时通过 Babylon 的 AnimationGroup 播放。

六种经营工作共用同一动作和短柄锤。当前外观、1 秒周期及动作幅度为功能试运行方案，
作业完成由任务工作时间决定，不按敲击次数发放资源。
原骨架的双脚保持中立支撑；先检查骨架与刚性脚掌、锤子代理的完整周期，再检查实际农民 GLB。

[实际 GLB 挥锤周期截图](hammer-cycle.png) 按 24 个等间隔相位排列；详细资源校验和本轮/历史审查范围见 [农民验证记录](../farmer/runtime-validation.json)。
