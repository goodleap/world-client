# 灰狼制作与动作来源

制作依据：world-design `动物原型图/灰狼原型-待评审-v1.png`，用户在 2026-11-02 明确回复“可以，开发吧”，确认该图用于制作。文件名与图中文字保留原始生成记录，确认状态以此记录和设计文档为准。

用户在实际 3D 检查中进一步明确：身体上的毛发层次是毛色变化，不是凸起物。因此躯干、背部和尾部采用连续曲面与顶点颜色分区，删除之前误做的片状凸起；不能把它们恢复为鳞片、装甲或悬挂零件。脸颊、胸颈和头顶仅按原型轮廓保留少量毛束。

源入口 `build_wolf.py` 从固定量化体积、连续面、轮廓毛束及关节生成 Blender 与 GLB；没有引用旧 Demo 狗的模型或几何生成逻辑。作者坐标为 +Y 前、+Z 上；整体缩放 0.72，导出后面向游戏 +Z。每只狼共享模型与动作源，但保有独立姿态。`wolf.json` 保存本次尺寸、关节及资源统计。

单只模型、骨架、连续动作及发布 LOD 已完成本轮实际渲染检查，并接入随机狼群。完整截图、动画分相、玩法验证与限制见 [交付记录](../../docs/wolf-raids/README.md)。用户最新反馈仍是后续调整依据。

`publish.py` 将同一模型合并为一个顶点色材质，离线发布三层几何，共享 16 骨架及 Idle／Run／Bite／Hurt／Feed。游戏通过一个 GLB 克隆独立骨骼，不能为每只狼重新发布完整资源。`wolf.blend` 保留发布前制作源；`motion-check.json` 是对该源 121 个连续姿态的定量结果。

```sh
blender -b --python studies/wolf/build_wolf.py
blender -b --python tools/check_wolf_motion.py
# 云端开发服务端口 4175；使用实际 Babylon 导入与渲染。
node tools/review_wolf.mjs
```
