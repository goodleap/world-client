# 基础人物 · 头身饱满度与跑步

当前为 v11 手脚细化，保留 v10 体积修订。依据设计仓库的基础人物原型及用户关于“头部瘪、身体需要更圆鼓饱满”的反馈，在已进入 Demo 的 v9 基础人物上重新调整头身曲面。头、耳朵及五官仍保留以颈部为锚整体缩至 92% 的比例，为发型和帽盔留空间；8% 是此前选定的取值，不是所有人物的统一比例标准。

本轮手脚：拇指与掌部连续连接，卷指仅保留局部浅褶；五趾大小、长度递减，趾根融入脚背。头部与躯干顶点保持 v10 数据，骨架与 Walk／Run 轨道不变。实际导出检查页为 `studies/review.html`，当前资源验证见 `runtime-validation.json`。

## 保留的头身体积调整

- 头部：保留现有高度、正面宽度与五官布局，增加额头、脸颊及后脑的前后体积，让脸部向两侧连续包转。五官跟随新的脸部曲面贴合，脸颊体积直接塑在头部网格内。
- 躯干：增加胸腹、腰背的厚度，腹部略鼓，向领口和腰部自然收拢。肩关节与四肢位置保持原方案，保留腋下空间。
- 服装：T 恤、衣摆与短裤腰臀同步贴合身体的新体积，避免仅加厚皮肤造成穿模或衣服悬空。

实际 GLB 静止网格的尺寸对比（H 沿用原始头高单位；不含耳朵和五官凸起）：

| 部位 | 修订前 | 修订后 |
| --- | --- | --- |
| 头部宽 × 高 | 0.940 × 0.920 H | 0.940 × 0.920 H |
| 头部前后厚度 | 0.863 H | 0.966 H |
| 躯干皮肤前后厚度 | 0.386 H | 0.466 H |
| T 恤前后厚度 | 0.440 H | 0.517 H |

用同相机、同中性光照对比实际 GLB 的正面、纯侧面、斜侧面、背面及游戏视角，并检查 180 × 240 缩小显示。跑步检查覆盖 16 个相位及 241 个连续运动数值样本，骨段长度与既定运动轨迹保持不变。耳廓、拳形及大幅抬臂时的袖缘仍有原有细节差距；本次头身体积修订不代表所有模型细节最终还原完成。

## 骨架先行

先固定骨段长度、关节轴向与活动范围，用骨架线段和完整尺寸的刚性脚掌代理设计连续运动；通过可达性、支撑锁地、周期连接和相邻姿势检查后，再套回现有网格，处理局部变形。不能仅凭单个姿势或骨骼角度不超限判断动作通过。

基础骨架共 20 根：原有根、骨盆、躯干、头、左右锁骨及四肢 18 根，加左右两根膝部变形辅助骨。膝、踝位置按短腿和脚体重新核对。脚掌主体随足骨保持体积，过渡集中在踝口；膝辅助骨缓解线性蒙皮收缩。游戏使用 glTF 线性蒙皮，不依赖仅 Blender 内有效的保持体积选项。

骨段尺寸、坐标、关节方向、上身姿态和跑步关键路径见 `rig-motion-plan.json`；`rig_motion.py` 是绑定脚本实际使用的轨迹来源。修改动作时先重新验证该代理，不另写一套逐帧独立拟合来替代它。

## 动作与游戏连接

- `Walk`：0.5 秒循环，参考速度 1.15。用于自由漫步，首帧为中立站姿，屈膝方向已校正。
- `Run`：0.45 秒循环，参考速度约 1.667。用于指令移动，包含落地承重、蹬伸、低位收腿和两段双脚离地；采用适合短粗腿的跑姿，不强行套用成人大幅后踢。
- 地图寻路负责位移。前端读取 `animation-metadata.json` 中的参考速度，按实际移速调整播放速度，保持步幅与位移配合。
- 到达或暂停时停止动作，再用 `Walk.reset()` 恢复中立站姿；Run 的首帧是运动相位，不能用它恢复站姿。

两动作时间从 0 开始，避免导出首帧偏移造成循环停顿。Run 按 120 FPS、54 个间隔采样，精确覆盖 0–0.45 秒。

## 文件与重建

- `base-human.glb`：游戏实际加载的网格、蒙皮与动作。
- `base-human.blend`：同版骨架源文件，保留 Walk、Run。
- `build_model.py`：生成静态 v11 形体；`MODEL_OUTPUT` 可将候选模型和审查图输出到独立云端目录。
- `bind_model.py`、`rig_motion.py`：缩头、绑定并按固定运动方案生成动作。
- `rig-motion-plan.json`、`animation-metadata.json`：骨架运动方案与前端播放参数。
- `rig-report.json`、`runtime-validation.json`：尺寸、导出信息及实际蒙皮验证记录。

参考原型保留在设计仓库，不复制到公开前端仓库。使用 Blender 4.3.2，在云端工作区重建：

```sh
MODEL_OUTPUT=/tmp/base-human-volume REVIEW_VIEWS=front,profile,game blender -b -t 8 --python studies/base-human/build_model.py -- v11
blender -b -t 8 --python studies/base-human/bind_model.py -- --input /tmp/base-human-volume/v11.blend --output /tmp/base-human-runtime
```

输出须经过实际 GLB 的完整动作周期、游戏视角及手机显示检查，再替换游戏文件。结构或数值检查不能代替视觉审查。

已知范围：当前用于站立、行走、奔跑。大幅抬臂时短袖肩缘仍需后续修整；工作、攻击等动作未制作，也未验证相应服装变形。
