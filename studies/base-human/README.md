# 基础人物 v9 · Demo 骨骼版

用户于 2026-10-29 同意将本轮 v9 造型放入游戏体验，并明确要求按新体型重新建立骨骼。此版沿用该静态模型的比例、头脸、服装和配色；没有导入旧 Demo 的身体或骨架。用户同意试用不表示耳廓、拳形等细节已达到最终还原标准。

## 文件

- `base-human.glb`：游戏实际加载的模型，带蒙皮及独立的 `Walk`、`Run` 动作。
- `base-human.blend`：同版骨骼源文件。
- `build_model.py`：从零建立 v9 形体的脚本。
- `bind_model.py`：整理导出几何、按新身体绑定并生成审查姿态的脚本。
- `rig-report.json`：骨骼名称、实际尺寸与导出整理的采样记录。

制作参考来自设计仓库的基础人物原型与尺寸说明，原型图不复制到公开前端仓库。模型头脸的几何及顶点色保留，衣服与肢体的高密度网格做了低误差导出整理；该记录不能替代实际渲染审查。

## 骨骼与动作

新骨架共 18 根：根、骨盆、躯干、头，以及左右锁骨、上臂、前臂、手掌、大腿、小腿、脚。肩、肘、髋、膝和脚踝位置按照 v9 身体重设；头脸随头骨刚性运动，四肢与衣服采用蒙皮过渡。

居民自由漫步使用 `Walk`，收到移动指令后使用 `Run`。地图寻路控制位移，客户端按实际移动速度调整播放速度，保持脚步节奏与位移同步。

- `Walk`：0.5 秒原地循环，参考移动速度 1.15，首尾帧为自然中立姿势。
- `Run`：1/3 秒原地循环，参考移动速度 2.1，包含身体前倾、屈肘摆臂、抬膝、腾空和落地；不是加速播放行走动作。
- 到达或暂停时停止两个动作，并将 `Walk` 重置到首帧恢复站姿；`Run` 的首帧本身是跑步姿态，不能用它恢复站姿。

已有实际静止、行走、奔跑侧面及游戏视角、落地、抬臂、弯肘与屈膝渲染检查。本版游戏使用范围为站立、行走与奔跑；未来工作、攻击或更大幅度动作需另行检查衣服与关节变形。

已知限制：约 76° 抬臂时短袖肩缘仍有牵扯，尚未通过该动作下的衣服蒙皮审查。骨骼关节位置和左右方向已核对；后续需要处理肩袖拓扑/权重，不能仅凭已有骨骼直接宣称能完成所有工作或战斗动作。

## 重建

使用 Blender 4.3.2。先生成静态源，再为其绑定；只在云端工作目录执行：

```sh
REVIEW_VIEWS=front,side blender -b -t 8 --python studies/base-human/build_model.py -- v9
blender -b -t 8 --python studies/base-human/bind_model.py -- --input studies/base-human/v9.blend --output /tmp/base-human-runtime
```

第二步输出 `base-human-v9-rig.glb`、同名 `.blend`、动作审查渲染和 `rig-report.json`。人工/AI 实际审查后再替换游戏文件，不直接覆盖现有发布资产。
