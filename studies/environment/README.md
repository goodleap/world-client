# 环境素材制作说明

本轮依据设计仓库的“地形植物资源农作物”“建筑与设施”原型，以及角色原型图中的“游戏内效果示意”，改善 Demo 的柔和卡通造型、色彩和受光。原型图片继续由设计仓库维护，不复制到公开前端仓库。

## 制作与运行

- `src/game/tree.ts`：不对称圆润树冠，黄绿色顶部、鲜绿中间色与深绿底部；通过不同规模与轻微色调变化复用同一树种。
- `build_tree_trunk.py`：用 Blender 4.3 的曲线、体素融合和平滑生成连续树干与根部，输出 `src/game/tree-trunk.json`。这份 JSON 是自制网格数据，运行游戏不需要 Blender。
- `src/game/environment-shapes.ts`：圆角轮廓与连续法线的基础形体、圆润植物体块及高度色阶。
- `src/game/buildings.ts`：弧形瓦片屋顶、奶油墙面、门窗、木框与石材。门洞宽高按当前人物尺度安排。
- `src/game/world.ts`：确定性绘制的草地与沙土色差、圆润作物、石岸、水面、小草和花朵；地图逻辑与可行走地形仍由 `world-data.ts` 管理。
- `src/game/lighting.ts`：统一日光、补光与模糊地面投影。树冠和屋瓦通过形体与材质表达局部明暗，避免小曲面自阴影产生错误色带。

从仓库根目录重新生成树干：

```sh
blender --background --factory-startup --python studies/environment/build_tree_trunk.py
```

此命令只用于素材制作。模型由本项目脚本生成，未使用外部素材或 Blender 插件，也未给客户端增加依赖。

## 审查范围

先检查单棵树的正面、侧面、游戏角度与缩小效果，再检查民房及整张地图的 PC 和手机实际渲染。第一轮树根、分叉的拼接边界已通过融合网格修正；叶冠暗部过黑、墙面发灰和小曲面自阴影条纹分别修正，不能用构建通过代替这些检查。

本轮目标是环境的形体与色彩方向。树皮细纹、建筑木纹等仍作简化，场景布局属于操作 Demo。农民尚未换成新版基础人物，其他人类角色仍为明确标注的基础人物占位；未把这些内容标记为完整原型还原。最终视觉判断由用户评审。
