# 农民角色试样

这是一个尚未通过原型还原审查的试样，供后续查看和修改。游戏中的农民使用此模型；点击视角控制中的“农”可放大查看，再次点击返回游戏视角。

- `farmer-scarf.blend`：可继续编辑的 Blender 源文件。
- `farmer-scarf.glb`：从该文件导出的 glTF 二进制模型。
- `base-human-rig.blend`、`base-human-rig.glb`：去除农民服饰后的基础人物和相同的基础骨骼、行走动作，供后续继续调整。
- `farmer-scarf-*.png`：正面、侧面、背面和游戏角度的 Blender 实际渲染。

参考设计仓库 `角色原型图/角色原型图-待评审-v1.png` 中的农民，以及 `角色原型图/农民角色比例与尺寸说明.md`。模型基于当前基础人物试样：包含身体、五官、头巾和服装。头巾覆盖头顶并延伸到后脑，前缘和刘海仍有穿插。发型、围裙、鞋子等与原型仍有明显差距，肩部动作也尚未解决。模型有躯干、手臂及腿部基础骨骼与简单行走动作；头部没有独立骨骼、脚部尚无独立关节和落脚约束，裤裆处在行走姿态下有不自然的折痕。该绑定仍是试验性质，不是完整角色动画系统。预览视角中会循环播放行走动作，便于观察。
