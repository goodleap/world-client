# 农民角色试样

这是一个尚未通过原型还原审查的试样，供后续查看和修改，尚未接入游戏。

- `farmer-scarf.blend`：可继续编辑的 Blender 源文件。
- `farmer-scarf.glb`：从该文件导出的 glTF 二进制模型，未进行游戏运行时验证。
- `farmer-scarf-*.png`：正面、侧面、背面和游戏角度的 Blender 实际渲染。

参考设计仓库 `角色原型图/角色原型图-待评审-v1.png` 中的农民，以及 `角色原型图/农民角色比例与尺寸说明.md`。模型基于当前基础人物试样：包含身体、五官、头巾和服装。头巾覆盖头顶并延伸到后脑，前缘和刘海仍有穿插。发型、围裙、鞋子等与原型仍有明显差距，肩部动作也尚未解决。仅有用于肩部实验的局部骨骼，并非可用的完整角色绑定。
