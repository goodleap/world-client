# 家园漫游 · 前端 Demo

Babylon.js + TypeScript + Vite 的 3D 前端技术演示。游戏使用独立的地图视角；角色与素材仍处于试样阶段，不代表正式游戏内容已完成。

## 运行

需要 Node.js 24 和 npm。在开发环境中执行：

```sh
npm ci
npm run dev
```

生产构建使用 `npm run build`，输出在 `dist/`。当前演示无需后端。

## 操作

- 点击人物或建筑选中；选中人物后点击空地，人物会寻找路线并前往目标。
- 拖动地图移动视角。电脑还可使用 WASD 或方向键移动视角。
- 鼠标滚轮、双指捏合或右侧加减按钮缩放；罗盘查看全景，回转箭头恢复初始视角。
- 点击右侧“农”可放大查看农民模型及其基础行走动作，再次点击返回。
- 点击右侧“人”可近看新版基础人物的站姿；支持缩放，再次点击或拖动地图返回。

单位连续移动；寻路使用网格搜索作为路线计算工具，避开地图障碍。目标被占用或无法到达时会提示，移动途中遇到其他单位可能等待或重新计算路线。未选中的居民会继续在各自活动范围内漫步。

基础人物使用用户同意进入 Demo 的 v9 造型，本轮头部整体缩小 8%，使用 18 根基础骨骼和 2 根膝部变形辅助骨，文件与重建脚本见 [studies/base-human](studies/base-human/README.md)。自由漫步播放 `Walk`，选中后指挥移动播放独立的 `Run`，到达后回到自然站姿。奔跑先用固定骨架与脚掌代理验证连续轨迹，再绑定到模型；播放节奏与移速读取同一份动作参数。工人、步兵、弓兵和骑兵同步使用新版基础人物占位及其动作，并在名称中标记；骑兵暂时不显示马匹，角色服饰与骑乘造型仍需制作。农民仍使用 `studies/farmer/` 中旧版 GLB 及行走动作，尚未迁移到新骨架；田园犬和场景也仍使用早期 Demo 素材，不代表已通过原型还原审查。

## 验证

```sh
npm run build
npm test
npm run test:e2e
```

浏览器测试会启动本地预览服务；若环境已安装 Chromium，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定其路径。测试覆盖相机操作、桌面和手机点选、单位指令、绕障寻路、农民动画及居民漫步。移动端真机性能与完整经营玩法尚未验证。

正式游戏设计以设计仓库中经确认的文档为依据。
