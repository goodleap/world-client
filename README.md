# 家园漫游 · 前端 Demo

Babylon.js + TypeScript + Vite 的 3D 前端技术演示。游戏使用独立的地图视角；角色与素材仍处于试样阶段，不代表正式游戏内容已完成。

## 运行

需要 Node.js 24 和 npm。在开发环境中执行：

```sh
npm ci
npm run dev
```

生产构建使用 `npm run build`，输出在 `dist/`。当前演示无需后端。

## 操作

- 启动先加载基础界面并进入菜单，点击“开始游戏”后加载地图和人物；两段进度独立显示，资源加载失败可重新加载。
- 游戏右上角显示 FPS 和 CPU 毫秒/帧，约每半秒更新；CPU 耗时测量游戏逻辑、渲染提交和标签更新，不使用帧间隔或 GPU 计时。
- 点击人物或建筑选中；选中人物后点击空地，人物会寻找路线并前往目标。
- 鼠标和触屏拖动地图时，相机直接跟随输入，松手后停止；电脑也可使用 WASD 或方向键。
- 鼠标滚轮、双指捏合或右侧加减按钮缩放；罗盘查看全景，回转箭头恢复初始视角。
- 点击右侧“农”可放大查看农民模型及其基础行走动作，再次点击返回。
- 点击右侧“人”可近看新版基础人物的站姿；支持缩放，再次点击或拖动地图返回。
- 切换标签页、失焦或离开页面时暂停渲染、动作和模拟；返回后清除残留输入，不补算离开时间。操作说明等手动暂停保持原状态。

单位连续移动；寻路使用网格搜索作为路线计算工具，避开地图障碍。目标被占用或无法到达时会提示，移动途中遇到其他单位可能等待或重新计算路线。未选中的居民会继续在各自活动范围内漫步。

指挥奔跑速度已在原先各角色速度基础上提高 50%（基础人物约 2.50 世界单位/秒、骑兵约 3.48）。Run／RideRun 的播放倍率按实际位移速度与动作参考速度计算，受阻或临近目标减速时也同步调整；漫步速度与基础模型资源保持不变。

基础人物保留用户同意进入 Demo 的比例及后续头身饱满度改进，本轮细化圆润拳形与大小有别的脚趾；头部整体缩小 8%，使用 18 根基础骨骼和 2 根膝部变形辅助骨，文件与重建脚本见 [studies/base-human](studies/base-human/README.md)。自由漫步播放 `Walk`，选中后指挥移动播放独立的 `Run`，到达后回到自然站姿。奔跑先用固定骨架与脚掌代理验证连续轨迹，再绑定到模型；播放节奏与移速读取同一份动作参数。步兵已按原型重做并接入共享移动逻辑，见 [studies/soldiers](studies/soldiers/README.md)。骑兵复用基础骑手，搭配新马匹、鞍具、披风与长矛，移动使用独立的 RideWalk／RideRun，到达恢复骑乘站姿。弓兵也已复用同一人物与步态重做，使用木弓、斜背箭筒和羽箭；工人仍使用基础人物占位，并在名称中标记。农民直接复用同一基础人物、骨架和 Walk／Run，加上按原型制作的头巾、头发、服饰、靴子和农具，见 [studies/farmer](studies/farmer/README.md)；田园犬仍为早期 Demo 素材。人物受光已随场景校准，但这不表示旧角色造型通过了原型还原审查。

## 场景美术

以设计仓库原型中的游戏效果、自然植物和民房为参考，重制圆润树冠与连续分叉树干、弧形橙红瓦屋顶、奶油墙面、青绿色门窗及圆润石材。草地和沙黄色小路使用确定性生成的细微色差，作物、小草和花朵用于补充原型中的色彩层次。

场景使用统一日光和柔和地面投影，植物色阶与局部体积由材质及顶点颜色共同表达。人物保持各自模型的肤色和服装颜色，校准受光强度。树根的碰撞范围同步新尺寸；相机操作、寻路和骨骼动作沿用已有逻辑。

源文件、重建方法和本轮审查范围见 [环境素材制作说明](studies/environment/README.md)。这些场景素材仍接受用户视觉评审，不代表整个游戏或全部角色已完成还原。

## 验证

```sh
npm run build
npm test
npm run test:e2e
```

浏览器测试会启动本地预览服务；若环境已安装 Chromium，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定其路径。测试覆盖相机操作、桌面和手机点选、单位指令、绕障寻路、农民动画、居民漫步，以及后台暂停、恢复首帧和手动暂停保持。移动端真机性能与完整经营玩法尚未验证。

正式游戏设计以设计仓库中经确认的文档为依据。
