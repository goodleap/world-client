# 第二批：性能设置与塔台

2026-11-02。对应用户第 6、7 项；第 1—5 项已独立提交在游戏 `6311970`、设计 `b3e9a6c`。

画面设置提供标准 60 FPS／省电 30 FPS／强省电 20 FPS。3D 缓冲区分别采用当前标准的 100%／80%／65%，DOM 不缩小；省电档降低太阳阴影尺寸并提前使用原生人物、狗 LOD，强省电关闭动态阴影，切回保留原阴影偏好。

逻辑与绘制分离：50 ms 固定步长，累计有效时间，无慢帧丢时；移动、生产、成长、招募、战斗、体力和袭击继续同速，暂停与后台排除。性能档位是本机偏好，重载保留。

塔台占地 2×2，木 20／石 12，耐久 300。一个弓兵预约后走到入口入驻，平台高 3.15，前移 0.85 改善俯视可读性。警戒和射程 12，不追击；原攻击和体力规则不变。支持查看驻守人、范围、撤出、编队移动离塔、下塔进食并自动返回。近战和狼攻击塔身，远程可打弓兵；倒塌清除建筑障碍并对驻守者结算一次 25% 最大生命伤害。状态随当前格式 14 保存，不做旧存档兼容。

模型复用原型中的石脚、木支撑、护栏、曲面橙瓦、蓝旗和梯子，原生实例共享几何与材质。审查时修正了斜撑末端连接和屋顶支柱，塔身细小倒角与屋瓦使用适宜分段，既有建筑精度保持不变。

## 当前限制

没有专用爬梯动作，入口与平台之间切换位置；其他建筑和地形的遮挡仍使用现有保守平面规则。云端 Chromium 为软件 GPU，不能给出真实手机功耗或温升结论；60／30／20 为绘制上限，设备不足时不会保证该帧率。标准生产构建仍有既有大体积 engine chunk 提示。
