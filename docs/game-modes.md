# 游戏准备与故事第一章

## 已实现范围

主菜单的“开始游戏”进入准备界面，默认故事模式、标准难度、家园名称“溪谷家园”。玩家可选故事／自由模式和轻松／标准／挑战难度；家园名称最多 24 个字符，空白使用默认名称。说明区显示实际起始库存和模式目标。手机内容区滚动，底部保留返回与进入世界；键盘可选单选项、提交，Escape 返回主菜单。

“进入世界”前重新检查浏览器存档。有现存数据（包括不可读数据）时确认替换；取消回到准备界面并保留选择，返回菜单也不改存档。新场景成功打开后保存，继续游戏读取存档中的配置。主菜单显示存档家园名称、模式和难度；家园资源面板显示所选名称。

## 故事第一章：迎接第一支商队

人物任务的流程为 **可接任务 → 接取 → 进行中 → 可交付 → 回报 → 待领奖 → 领取奖励**。满足条件只改变交付状态，不会自动接取、跳到下一项或发奖。前两项领奖后，领头提供下一项新委托，仍需玩家主动接取。

| 委托 | 人物与目标 | 交接及奖励 |
| --- | --- | --- |
| 先让粮仓充实起来 | 农民·领头；收获过一块农田，备齐 20 份未预留的入库粮食，地面及在途粮食不计入 | 回报后领取木材 6、石材 4；此项不扣粮食 |
| 打通西侧商路 | 农民·领头；通过实际战斗清理西侧路口守卫，日志可定位守点 | 回报后领取粮食 8、铁矿 4 |
| 迎接第一支商队 | 向领头接取，在家园中心 30 世界单位内点燃火堆，交付 20 份可用粮食 | 45 游戏秒后木匠阿榆实际入驻；与阿榆交谈、回报，再二选一领取赠礼 |

商队赠礼为工具升一级＋木材 12／铁矿 8，或粮食 24／石材 16；工具满级时只可选物资。物资领取后落在交接人物旁，由农民实际运输入库。领取回执列出所得数量，下一项委托不会自动接取。

阿榆入驻发生在领奖前，使用招募的人口上限、出口净空及人物初始化。人口已满、出口受阻或家园火堆熄灭时等待；暂停、对话、日志和切后台不推进抵达倒计时。入驻、已回报待领奖及最终选择均保存，重复点击或旧对话回调不能重复扣粮、入驻、发奖。任务人物死亡后，由其他存活居民接替交接，不复活人物；阿榆死亡时，接替者使用代交赠礼的台词。

第一章期间不触发常规家园袭击，野外守卫和野狼保持实际威胁。完成后继续经营、探索和家园防守；常规来袭在相应难度保护期后恢复。自由模式没有任务人物标记和章节限制。本轮使用现有角色、战斗、生产及补给，不包含护送路径、新商队行进模型、新作物或后续章节。

## 人物与界面

- 任务人物头顶显示 `!`（可接）、`…`（进行中）、`?`（可交付）、`礼`（待领奖），点击标记或待交接人物打开对话。选中人物的信息卡也提供“交谈 · 任务”。
- 状态变化时人物发出短句气泡；交谈显示说话人、气泡台词、目标和奖励预览。关闭对话不会接取或结算任务。
- 进入未完成的故事或定位人物时，镜头对准当前交接人，窄屏让开左侧日志。对话沿用原生 `dialog` 暂停世界，人物保留在下方对话框上方，临时淡出操作栏。内容内部滚动，接取／交接／领奖与关闭按钮固定在底部；对话背景保持清晰，关闭后重新定位人物供继续操作。
- 任务日志记录三项委托的状态并定位当前人物。日志只用于查阅，必须打开人物对话才能接取、回报或领奖。

## 实现与验证入口

- 原生 `form`、`fieldset`、单选控件和 `dialog` 复用现有页面、暂停和 Worker UI 通道。
- `game-setup.ts` 统一模式、难度与名称规则；`story.ts` 负责领取、回报、奖励和人物交接规则；`story-ui.ts` 负责原生 DOM 标记、对话与日志。时间、库存、人物与奖励由 Simulation Worker 负责，命令包含人物和章节标识；Render Worker 只显示状态和发出命令。
- 人物沿用现有共享农民资源和招募初始化，导航、渲染及动画使用现有 Babylon／Recast 集成。没有新增引擎依赖或制作新的角色模型。
- 存档版本为 33，保存任务交接状态，严格检查状态与章节、时间、奖励及居民关系；不兼容旧版。
- 逻辑检查：`node --import ./tests/native-test-runtime.ts --test --test-isolation=none tests/game-setup.test.ts tests/story.test.ts`。
- 模拟集成检查：`node --test tests/story-runtime.integration.ts`，覆盖木匠到达后注册实际角色、暂停回报、保存未领奖状态、重载领奖与重复请求。
- 浏览器检查：`npm run test:e2e -- preparation.mobile.spec.ts preparation.desktop.spec.ts story.mobile.spec.ts continue.mobile.spec.ts worker-startup.mobile.spec.ts environment-loading.mobile.spec.ts`。使用正式地图配置，系统 Chromium 可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。
