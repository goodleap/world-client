# 统一死亡退场（2026-11-02）

士兵、据点敌军与灰狼沿用第一项的死亡判定，增加同一退场过程：0.6 游戏秒侧向倒地，完整躺倒后停留 2 秒，再用 3 秒下沉；总计 5.6 秒。死亡时已退出指挥、碰撞占位、人口和进食，尸体网格也不拦截点击。

Fighter.diedAt 与经济游戏时钟一起保存。表现直接由 seconds - diedAt 采样，设置／后台暂停不推进；重载恢复当前阶段。旧版本没有时间戳的已死亡单位视作已经退场，不补播死亡。存档校验拒绝活人携带死亡时间、负值和未来时间。巡逻敌军既有再生机制开始新周期时清除旧时间。

复用现有中立姿态、骨骼与材质，用 Babylon Animation / AnimationGroup 采样根节点旋转与垂直位移。首次进入退场读取一次原生蒙皮后的顶点，预计算倒地轨迹的地面支撑高度，随后只采样少量关键帧；无布娃娃、粒子、额外灯光或常驻逐顶点计算。骑兵的骑手和马保留各自骨架、同一组合根节点与骑乘待机姿势，选择远离长矛的马匹侧腹方向一起侧倒和下沉，避免只转骑手造成悬空或拆散坐骑。

死亡表现不负责伤害、战利品或据点结算。原结算状态与奖励保持独立，重新加载不会因播放动画再结算。灰狼事件结束后池仍保留死亡模型到退场结束；下一波再使用时清理表现状态。

验证入口为 studies/death.html（role=infantry / archer / cavalry / wolf）；相同运行时代码用于姿态审查，evidence 包含各阶段与侧面截图。逻辑覆盖贴地、暂停采样、完整下沉、旧存档、不合法时间及狼群奖励幂等。浏览器用例覆盖真实场景中停留时暂停、下沉中保存重载及最终消失。

本轮为低成本统一侧倒，未增加逐关节死亡表演或物理布娃娃。云端软件 WebGL 验证不等同于手机真机帧率验收。

验证结果：类型检查、生产构建通过；29 项相关逻辑检查通过；实际游戏死亡、暂停、存档重载和一次结算浏览器用例通过。侧面复验将骑兵倒向无长矛的一侧，防止武器先触地而抬高坐骑。
