# 田园犬重做（2026-11-02）

依据设计仓库 `角色原型图/角色原型图-待评审-v1.png` 下排「中华田园犬」。用户提及的 `动物原型图/农场动物.png` 实际只有鸡、羊、牛，用于风格参考；没有另生成犬原型。犬参考只有一个侧前视图，背面、完整步态和隐藏结构按其体积关系补全。

## 形体与渲染检查

新建 Blender 曲面模型，替换原来球体、软方块和三角柱耳朵的运行时拼装。躯干和四肢离线融合成连续体积；大额头与脸颊、短口鼻、圆厚耳片、胸腹、脚掌和卷尾分别塑形。颜色使用曲面顶点色，一份哑光 PBR 材质，无毛发、透明层或额外贴图。

| 项目 | 本轮实际渲染自检 |
| --- | --- |
| 头身比例 | 大头、短圆四肢、紧凑躯干，约 1.44 m 高，低于约 2.4 m 的人物和坐骑。 |
| 脸部 | 宽额头、饱满脸颊、短口鼻、黑色椭圆眼及小高光、圆鼻、开口微笑和舌头；侧面有实际厚度。 |
| 胸腹与腿爪 | 胸腹为连续曲面，奶油色胸口跟随表面；短腿与身体连续蒙皮，脚掌独立刚性跟随。 |
| 耳尾与色彩 | 厚实圆尖立耳、珊瑚色耳内、较紧凑的上卷尾、暖橙毛色和奶油色尾端；首轮过大的尾环已缩小。 |
| 动作与变形 | 检查原生连续 Walk、Run、Feed，以及 Idle 待机；无脚掌穿地、明显断裂或脱离躯干。 |
| 游戏与手机 | 实际地图中与人物、马和建筑同屏；120×150 模型缩略渲染与 412×839 手机游戏截图均保留犬的识别轮廓。 |

正、侧、背、斜俯视与游戏光照下三档模型截图在 `evidence/`。`*-motion.mp4` 记录每个动作 120 个连续 Babylon 动画/渲染帧（原生固定动画步长 16 ms，每两帧取图，以 31.25 fps 输出，共 1.92 秒）；`*-continuous.png` 是对应连续播放片段的抽帧。另检查各动作至少三个真实循环和八个相位。视频来自引擎实际播放，未用关键姿态图片插值合成。视觉自检结果可供用户复审，不代表用户已确认最终美术。

## 骨架、动作与性能

16 骨：躯干、头、下颌、尾和四肢各三骨。固定关节坐标、步幅、支撑占比、相位和时长保存在 `studies/dog/dog.json`，离线 IK 不进入游戏运行时。Walk 为 0.8 秒/0.72 m（参考 0.9 m/s），Run 为 0.5 秒/1.05 m（参考 2.1 m/s），Idle 2.4 秒，Feed 1.2 秒。导航速度仍由原系统决定，动画按实际位移调速；没有更改生命、体力、进食消耗或避险规则。

资源 `studies/dog/dog.glb` 约 1.1 MB，三档分别 15,898 / 6,546 / 2,244 个三角形。共用原生 Skeleton、材质与动作，LOD 复用项目现有 Babylon 屏幕覆盖率选择及阴影通道。普通地图及远景用两档简化几何，近看保留圆润轮廓。远档放大检查时眼睛等小细节可见简化，正常地图视距下不单独渲染高档细节。

修正了旧动物停下休整时跳过动画更新、可能仍播放奔跑的问题。现有居民根节点、命令与存档结构继续使用；进食时切换 Feed，设置/后台暂停冻结原生动画时钟。保存后从生命、体力、路线、休整及餐食剩余量继续；不保存纯装饰动作的瞬时相位。

新增犬文件纳入真实字节下载汇总、独立解析与挂接阶段。解析总权重仍为 20，狼/犬挂接合计仍为 4，完成前仍等待场景与首帧，不因增加资源突破 100%。

最终生产构建实测首次下载与持久缓存重载，分别观察到 62 / 61 个不同进度值。犬 GLB 为 1,055,564 字节，首次实际传输 1,055,864 字节，缓存重载仅传输 300 字节响应头；五个 GLB 均命中内容缓存，解析、挂接、场景就绪和首帧继续正常执行。详见 `evidence/loading-cache.json`，未用计时器补百分比。

## 验证与复现

- 38 项相关逻辑检查通过：直接加载发布 GLB，检查三档共用骨架/材质、全部动作循环与暂停、绑定矩阵不变；命令、进食、避险、生命/体力和保存逻辑。
- Blender 对四动作各采样 121 帧，最小脚掌高度 ≥ 0.00046 m，骨长最大误差 < 0.00000013 m，首尾接缝为 0，目标可达裁剪为 0。详见 `studies/dog/motion-check.json`。
- 桌面浏览器点击奔跑、改向、到达与步频匹配通过；手机浏览器进食恢复、暂停冻结、保存重载、触摸覆盖指令通过。相关截图、日志在 `evidence/`。
- 类型检查和生产构建通过。保留已有引擎大 chunk 提示；云端 Chromium 软件 WebGL 的帧率不能作为手机真机性能结果，未覆盖 iOS Safari 真机。
