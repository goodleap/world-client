# 火堆、体力、门动画与单兵操作

后续操作、30 格内低体力进食和全职业火堆补给已按最新要求调整，见[本轮交付记录](../controls-and-feeding/implementation.md)。以下保留当轮实现与验证记录。

2026-11-01。在首轮战斗基础上按用户最新要求实现，并替代原来的小队与回家恢复规则。

## 已实现

- 8 石材建造石圈火堆；熄火、燃烧、实际烹饪三状态。点火持续消耗本地木材；开关保留剩余燃料和加工进度，无人需要新餐时不消耗粮食。
- 农民从仓库取货送往火堆，木材每批最多 6、粮食最多 4，各自本地容量 12。复用任务预留、寻路、避让与 Goods 在途状态，中断落地、恢复拾取原货、取消返库，不复制资源。
- 所有居民与动物拥有体力/生命状态，骑手与马独立消耗餐份。低体力减慢移动、作业并延长攻击间隔；保留最低 50% 效率避免断粮死锁。选中后“进食”或指定火堆，空闲时可自动就餐，按不同站位接近。
- 一份熟食用 6 游戏秒逐渐恢复 45 体力、12 生命；战败士兵原地受伤、可缓慢移动就餐。移除自动回家、直接扣仓库粮食和计时回满流程。无永久死亡。
- 移除小队入口和成组选择；每次只控制选中的单兵，切换/取消选择不撤销已有命令。移动、攻击、撤退保留选择，生产任务成功释放选择。
- 每座房屋/仓库有独立原生门轴动画；仓库真实存取触发开、停、关。所有流程随统一游戏时间暂停，返回需要手动继续。存档 v7 保存途中配送、燃料、烹饪、餐份与生命体力，旧档不迁移。

试行参数集中在 `src/game/campfire.ts`、`vitals.ts`、`combat-config.ts`。设计见 world-design 的 `玩法设计/基础经营/火堆与体力.md`。

## 验证

- 类型检查和生产构建：通过。Vite 保留引擎大分块提示。
- 逻辑测试：138 项通过，包含原战斗/生产回归、门轴、石材建造、火堆启停、不同帧长烹饪、供给中断/返库/容量、独立餐份、体力消耗、受伤进食、严格存档与两灯预算、受击不取消赴餐路线、马匹在真实地图可达就餐站位。
- 浏览器：6 个相关场景经分批运行和修复复测均通过。桌面覆盖建造/取货/交付/烹饪/受伤恢复/暂停/读档、单兵独立命令、奖励唯一性；手机覆盖狗/骑手/马独立进食、手动移动打断休整、指挥气泡清理、设置居中与触控战斗。最终马匹流程在扩大站位后复测通过。
- 验证发现马匹碰撞体无法进入原 3.5 半径站位，已扩大为 4，并加入实际地图可达性回归；被占用的位置也不能被移动指令的远处候选点替代，避免离开供餐点进食。

## 当前边界

这些数值为试行值。没有新肉类/饲料商品、食谱、饥饿死亡或进食骨骼动作；人物在火堆站位待机进食。农民、狗与骑兵首轮仍不成为敌方攻击目标；敌方有体力但没有独立供餐调度。其他房屋已具备门轴，但尚无新的出入屋玩法；本轮由仓库真实存取触发门动画。两盏照明只分配给距离镜头最近的燃烧火堆，其他火堆仍有火焰。

云端 Chromium/SwiftShader 与手机视口检查不代表真实 iPhone 性能。
