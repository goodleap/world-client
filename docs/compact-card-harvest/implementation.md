# 第三批：紧凑信息、自然产出与操作反馈

2026-11-02。本次三批的最后一批，包含开发中用户追加的箭头加密及圆角、放大取消按钮、加粗头顶血条、攻击目标脚下内收箭头。旧存档不兼容，当前存档版本 v12。

## 信息与交互

单位卡固定在底部中间，桌面高 48、手机高 41 CSS 像素，与四角按钮一致。左侧两行是名称和活动，中间是生命／体力两条条形图及小号当前值／上限，去掉可见文字标签，无障碍名称保留。右侧取消叉号桌面 30、手机 28 像素，点击宽度分别 38、36；领头的“指挥”在取消左边，卡片在空间允许时加长。骑兵只显示骑手，马的独立状态和进食不变。

建造栏继续横向排列，手机支持横向滑动和向上拖入地图；信息卡不再额外抬高建造栏。作业命令接受后仍取消选择，查看卡片不下达任何命令。

头顶血条从 32×3 增为 52×7 CSS 像素，浅边、暗底和轻阴影提高对比，仍在名称上方留 5 像素间隔。生命变化后显示 4 游戏秒；首次载入伤势不触发，暂停冻结。发言气泡根据正在显示的血条行数避让。

## 路线和攻击反馈

引导带按用户图片改为分开的折角箭头，浅色填充、灰蓝描边；尖头、内侧转角和尾部边缘采用圆角。宽约 0.84 世界单位，间距从 1.5 缩短到 1.0；弯道及终点留出空间，保留小终点菱形。直接使用真实剩余路线，移动／赴工／运输／赴餐／追击适用，闲逛不显示。圆角轮廓和三角化在创建时计算一次，所有箭头继续使用一个网格、一个材质，没有粒子或额外渲染通道。

攻击命令被接受后，名称旁保持红色交叉剑，脚下另有四个红色箭头向内收拢，约 0.8 游戏秒后淡出。复用移动反馈的 Babylon AnimationGroup，攻击实例去掉圆环；箭头跟随目标实际位置，取消选择、改为移动、目标死亡或攻击失效时清理。暂停冻结；这类瞬时反馈不保存，重载仅恢复实际攻击目标。

## 成长与地面模型

胡萝卜由 25 增为 75 游戏秒，小麦由 40 增为 120 秒，均是原来的 3 倍；开垦／播种／收获仍各 3 秒有效作业，产量仍为 8／12。暂停和后台不成长，当前版本重载保留实际秒数。

地面资源按来源使用模型：

| 来源 | 地面外观 | 每批三角形数 |
| --- | --- | ---: |
| 胡萝卜 | 两个带叶成熟模型平放 | 6,272 |
| 小麦 | 原成熟作物的三组茎穗平放 | 7,152 |
| 木材 | 三根横置原木，切面朝斜前方 | 720 |
| 石材／铁矿 | 三块原矿模型分别落地，铁矿保留锈色 | 1,728 |
| 无作物来源粮食 | 小粮袋与少量谷粒 | 2,322 |

成熟植株与收获物共用 `crop-model.ts` 形体定义；`ground-goods-model.ts` 只定义地面展示，不改变产出、运输或仓库数据。每种模板按材质合并后缓存，各批使用 Babylon 实例；表示数量固定，不随资源数额生成更多模型。石块逐个计算接地，原木有切面；地面模型最低 Y 约 0.005，农田上的产出叠加土垄高度。采集来源、完整数量、拾取、在途隐藏、部分入库与存档均仍由经营系统控制。

## 验证与证据

- 逻辑测试 192/192，通过当前版本成长、保存、资源数量守恒、独立坐骑状态、目标规则等检查；追加攻击箭头后，移动反馈、生命显示和单位卡定向测试 7/7。
- TypeScript 与生产构建通过。
- 单位卡与路线桌面／手机浏览器 4/4；检查 1280×900、393×852、320×568、844×390，包含建造横滑、拖放、骑兵两条、领头开关、放大取消按钮、暂停及实际选择保持。
- 最终取消叉号收紧 SVG 留白，使图形本身接近两行文字高度；追加真实页面四种视口截图与点击取消检查通过，卡片及建造栏无重叠。
- 自然资源实际游戏回归通过：六类模型、作物来源和数量、存档重载、真实网格点击、拾取时从地面移除、交付后才加仓库。
- 最终资源／血条／攻击反馈浏览器回归 5/5（约 5.5 分钟）：桌面四边缘与恢复暂停、手机狗／骑兵／马恢复、两种视口的攻击箭头跟随和暂停、取消清理均通过；地面资源回归包含其中。
- `tools/review_ground_goods.mjs` 使用 Babylon 实际源模型与游戏光照，逐一检查正面、侧面、游戏角度和手机缩小效果。校准矿石分别接地及原木切面后复查。

主要画面位于 [evidence](evidence/)：`desktop/mobile-card-build-*`、`final-leader-card-*`、`selected-path`、`selected-attack`、`farmer-healing-desktop`、`meals-mobile`、`ground-goods-*` 以及六种资源的 `front/side/game/mobile`。

限制：云端 Chromium 为软件 WebGL，手机检查是视口与实际 3D 缩小渲染，不能替代实体手机 GPU 性能测试。地面产出采用当前已有作物／矿石形体；代表模型数与实际资源数量独立，没有新增手持搬运外观。
