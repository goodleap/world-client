# 通行、危险作业与拆除第二批（2026-11-03）

本页是上一批历史记录；骑兵胶囊已由[移动连续性批次](../movement-continuity/implementation.md)替换为半径 0.6 的圆。危险作业、拆除和拾取修复继续保留。

本批包含讨论中的第 5／7／12 项，以及追加的建筑外误选修复。

## 实现

- 骑兵为半径 0.46、中心线半长 0.64 的定向胶囊（总长 2.20、宽 0.92）。方向进入 A* 状态；指令验证、平移、转身及邻居避让使用相同形状。转动上限 4 弧度／秒，转动采样有覆盖采样间隙的几何余量，直行扫掠为完整长胶囊。近战追赶的即时路径同样校验胶囊，保留原有移动目标预测。
- 空闲友军寻找安全侧移点；不打断已接受任务、进食、驻守。相同方向经过窄处时排队，出口后继续走向各自目标。建筑占地与现有碰撞形状不变。
- 派工验证目标和去回路线；危险任务共同暂停，保存进度、材料、掉落物及安全计时。每 0.5 游戏秒检查，连续安全 5 秒后释放，其余安全任务可继续。改作业点、仓库变更后的新路线也检查。
- 玩家放置的民房、仓库、火堆、哨塔及耕地可拆除；开局固定三座建筑保留。两处入口均有确认弹窗。完工建筑返还基础木石的一半至地面；未完工释放预留；火堆剩余供餐物资保留。缩小仓库容量的多余库存落地，清理关联任务及攻击。哨塔先安全撤出，堵住出口时保留建筑。
- 自定义拾取漏掉 `isPickable`，导致带建筑标识的原生 LOD 在其局部坐标参与拾取。恢复原生启用／可见／可拾取检查，排除显示用 LOD，正式建筑和实例保持可选。
- 存档版本 18，无旧版本迁移。

## 验证

仅进行一次完整逻辑回归：269 项中发现 4 处失败，其中两处是骑兵追击适配遗漏，两处为旧规则断言。修正并只重跑相关组；随后加入 LOD 拾取回归，全部针对性复测通过。胶囊与原有避让首轮 15 项通过，补齐到达点与 Worker 路线采纳后，相关 21 项通过；实际地图检查用真实胶囊验证地形和单位间不穿透。拆除资源守恒、重复操作、满仓溢出、火堆在途供给、哨塔安全撤出，以及危险路线、共享暂停、连续安全计时和保存重载均通过。

桌面 Chromium 和手机触控用例通过：三叉路口外部点击、三座真实建筑点击、确认取消／拆除、资源留地、列表更新以及骑兵实际移动。首次桌面测试拖动起点被选中提示覆盖，改为先取消选择后单独复跑通过。实际查看游戏、确认弹窗和手机清单；连续移动姿态由浏览器采样。手机视觉检查发现并修复耕地误标「已损毁」，最终手机清单显示「种植中／空地」、生命／防御为「—」。生产构建包含类型检查并通过。

## 边界

没有引入完整 3D 物理或新模型资源；现有二维规则、导航 Worker、存档继续复用。通道窄于身体或持续被占时仍可能等待，未实现全地图交通预约。危险判定依据现有敌人和视线，不能预知未来生成的敌袭。云端为软件 WebGL，桌面／手机视口验证不代表实体 iPhone 的帧率或功耗。
