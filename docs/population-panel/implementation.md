# 家园资源与人口面板

2026-11-03，家园面板改为“资源”“人口”两个页签。人口页每个存活我方单位一行，显示名称、生命当前／上限、体力当前／上限和攻击／护甲。攻击、护甲使用与实际战斗相同的装备升级计算；生命从战斗或生理状态读取，体力沿用单位卡的显示口径。低于 30% 标红。

新招募单位自动加入清单，死亡单位移除，刷新后仍保持。人物人口数与田园犬数量分别显示，敌军与坐骑不列入；骑兵显示骑手自身数值。农民和狗的攻击显示“—”，护甲为 0。

编队编辑放在人口页：仍有 4 队、每队最多 6 名，勾选成员后保存。成员在其他队时显示队号；保存、清空和独占成员规则延续。右侧队号按钮继续用于快速选择和指挥全队。查看面板暂停模拟，查看数值不改任务、不消耗资源。关闭期间不重建人口列表；再次打开读取最新数值。

布局采用原生表格、纵向滚动和紧凑数值列，手机保持每单位一行，表头随列表滚动固定。矮屏将人数与队号放在同一排并收紧标题区，让名单和保存按钮同时可见。原生 DOM 即可完成，无新增模型、材质或渲染成本。

验证：232 项逻辑测试、TypeScript 检查和生产构建通过。新增测试覆盖实际生命／体力、装备升级、新招募、死亡、犬与坐骑口径，以及查看不改变存档。桌面／手机两项完整浏览器流程通过，覆盖数值与实际快照一致、暂停、资源／人口切换、保存编队、右侧按钮全队移动、招募与取消、存档重载。320×568 窄屏与 844×390 横屏的表格无横向溢出，面板和保存按钮位于视口内；原有底部单位卡居中布局也继续通过。已实际查看桌面编队表、手机竖屏和横屏渲染，截图保存在本目录。

复现：`npm test`；`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npx playwright test tests/e2e/home-management.desktop.spec.ts tests/e2e/home-management.mobile.spec.ts`（包含 TypeScript 与生产构建）。剩余限制：浏览器使用云端软件 WebGL，未测实体手机的帧率与功耗。
