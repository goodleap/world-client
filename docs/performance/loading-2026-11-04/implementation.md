实际变更：

- Babylon 原生 `AssetContainer.instantiateModelsToScene` 的 predicate 同时筛选职业动作。农民保留走、跑、作业；步兵、弓兵保留本职业走跑和攻击；骑兵保留骑乘、攻击、马匹动作及倒地姿态所需 Walk。共用关键帧和独立角色状态不变。106 名人类、1 只狗及灰狼池均照常创建。
- 蒙皮合批使用原生 Geometry 解绑/绑定，省去先复制原几何再覆盖的步骤；合并数据以 float32/整型缓冲保留，索引合并显式复制以保护模板。地图合批完成后，在人物实例化前按小批次把普通数组收紧为类型数组。继续保留 CPU 顶点、索引、拾取和 WebGL 恢复数据，不调用强制 GC。
- 94% 后以约 8 ms／最多 64 项为一批检查原生 `Mesh.isReady(true)` 和纹理，批间让出绘制机会，最后保留 `Scene.whenReadyAsync` 全部就绪条件。单次驱动调用仍可能超过预算，8 ms 不是硬实时保证。渲染循环在材质准备后启动，游戏逻辑和自动保存在首帧完成后才启用，加载等待不计入游戏时间。
