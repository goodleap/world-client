# 人物远景与建筑分级：第二批

用户授权在已有圆润形体、材质、动作和玩法基础上降低手机渲染负载。此次只重建人物的远景派生资源，并为房屋补上 Babylon 原生 LOD；近景人物、骨架、动画和建筑原始形体保持原样。

## 实现

- 人物远景生成器固定 meshoptimizer 1.3.0，目标比例从 22% 调为 8%，小部件也参与。绝对误差上限仍为 0.008；所有混合蒙皮顶点及骨骼边界锁定，保留的顶点属性逐字节复制。关节因此仍有明确的减面下限。
- 远景文件从 3,175,068 降至 2,182,924 字节；资源部件合计三角形从 124,146 降至 85,426，均减少约 31%。整个人物组合中，农民 47,254→34,304，步兵 45,102→31,884，弓兵 49,356→32,656，骑兵含马 67,482→47,690。
- 小屋、仓库、家园中心按材质共享三个级别。只减少圆角和椭球细分，不移除瓦片、窗框、花盒或旗帜。近/中/远的圆角细分分别为 3/2/1，椭球段数 16/8/4。主相机投影世界面积达到 180/650 时进入中/远级；阴影继续通过自己的 LOD 相机选择。活动门保持独立。
- 后续建造使用缓存模板及原生 Instances。选中的实例临时克隆继续共享几何，复制原 LOD 和正确的位置，取消后释放临时节点。主画面与阴影使用各自的原生实例缓存。
- 精简日志新增建筑实际采用的近/中/远部件数，不把“存在 LOD 文件”当成“已经生效”。

## 验证与复现

- 类型检查、生产构建、237 项逻辑测试；原生 LOD 测试检查材料/部件/范围、变换、实例选择、取消和释放。
- 四种人物各 32 组动作相位/视角对照，涵盖正面、侧面、游戏视角和手机缩小；每种人物两种动作各播放两个完整原生循环。实际检查截图，未出现关节开裂、骑乘错位或明显轮廓丢失。三栋建筑的三个级别、四个视角均实际渲染。
- 生产构建的桌面/手机回归覆盖选中、日志通道加总与体积、暂停、画质切换和保存重载。仓库搬运用例补上在关闭领头派工时缺少的明确搬运任务。
