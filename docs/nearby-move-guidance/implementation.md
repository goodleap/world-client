# 附近可达落点与固定地面引导带

2026-11-02，前三批交付后的用户追加调整。保持当前 v12 存档格式。

## 行为

- 手动移动先尝试原点击点；障碍、其他单位占用、地图边界或不连通区域导致不可达时，搜索点击点半径 **3 世界单位**内的可达空位。以现有 **0.5 世界单位**导航网格选择离点击点最近的位置，再沿安全线段向点击点细化，精度约 0.003 世界单位。
- “最近”受导航网格采样精度约束，细化的是已选方向，并非连续空间的全局几何最优解。角色半径、障碍扫掠和其他单位的目标预约全部保留；骑兵使用坐骑半径。
- 首个目标不可达时，复用同一次 A* 已遍历的可达区域与父节点链，避免为每个候选重复搜索全图。正常直达路径仍直接返回。
- 细化后如最后一段会切角，保留原接近点。移动落点反馈、引导带终点与保存的移动目标都使用实际接受的位置。范围内无解才提示“无法到达该位置”，原指令保持；不会无限扩张搜索范围。作业、仓库、进食等明确交互位置沿用严格接近规则。
- 引导带的圆角箭头保持 **1.0** 间距、约 **0.84** 宽，固定在地面。单位前进时，只改变已接近箭头的透明度：沿路线距离脚边 **1.8 → 0.6** 世界单位，由完全显示渐隐至消失；经过后的箭头不会因微小避让退步重新出现。
- 消耗路点不重建箭头；真正重规划、换目标或换选择才更新几何。间距从终点计算，未变动的路线尾部保持原位置。停步、设置暂停时透明度冻结，抵达或取消选择清理。
- 填充和选中圈共用 `UNIT_SELECTION_COLOR = #62e4ff`，描边为同色相深色。仍只有一个共享材质和一个不可拾取网格；平时只更新顶点透明度，无滚动纹理、计时器、粒子或额外渲染通道。
