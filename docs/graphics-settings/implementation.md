# 主设置与画面预览

2026-11-02 按用户要求，主设置恢复背景虚化，光照和阴影移入单独的右侧画面设置。

## 行为与实现

- 主设置保持居中，背景沿用家园资源面板的 5 CSS 像素虚化与浅色遮罩。新增“画面设置”入口，继续游戏、操作说明、回主菜单、退出和性能诊断留在主设置。
- 画面设置在屏幕右侧显示，包含阴影开关、环境补光、太阳光强度与颜色、恢复默认光照。进入时关闭主设置及其遮罩；画面侧栏使用完全透明、无虚化的原生 `dialog::backdrop`，不改变场景的明暗与颜色，仍阻止下层输入。
- 使用现有原生 `showModal()` 与 `close()` 切换，先打开目的面板再关闭来源面板，避免出现未暂停的间隙。“返回设置”或 Escape 回到居中的主设置；点击侧栏外不会关闭或操作地图。只有主设置的“继续游戏”恢复运行。
- 复用现有 Babylon 按需刷新：调节参数后渲染暂停场景，空闲后停止渲染循环，角色、动画、战斗、经营与游戏时钟不推进。切后台保存进度，返回主设置后仍需手动继续。光照与阴影偏好继续保存在浏览器，失败提示显示在当前面板内。
- 桌面侧栏宽 276 CSS 像素；宽度不超过 600 像素时缩为 `min(224px, 60vw)`。右侧与上下保留边距及安全区，矮屏内部滚动，返回及重置按钮至少高 44 CSS 像素。新增 WebKit 虚化前缀用于支持相应浏览器；未进行 Safari 真机验证。

代码入口：`src/ui.ts` 的 `graphics-dialog`、`switchDialog` 和弹窗事件，`src/style.css` 的 `.graphics-dialog` 与 `::backdrop`。游戏渲染、暂停和光照计算沿用 `src/game/game.ts`，没有新增后处理或游戏循环。

## 验证

类型检查、生产构建和 164 项逻辑测试通过。桌面／手机光照设置和桌面阴影开关 3 项浏览器测试全部通过，覆盖：

- 主设置虚化与家园资源一致，进入画面设置后只保留一个打开的弹窗，背景无虚化、无调色。
- 修改环境补光、太阳光强度及颜色时产生新的渲染帧；参数即时生效，空闲后无持续渲染，暂停时人物、战斗、资源与游戏时钟不变。
- 透明背景输入隔离，返回按钮、Escape、切后台和手动继续；保存、重新进入以及恢复默认值。
- 阴影关闭后不再提交阴影绘制，重新开启与重载保存正常。
- 手机触控及 393×852、320×568、820×400 视口的右侧定位、内部滚动、返回与重置可达。

初次验证发现测试把后台保存更新的居民位置缓存当成了移动，以及未等待原生弹窗异步关闭事件。修正为比较实时居民与其余经营状态，并等待恢复循环后复测；未更改游戏逻辑。验证结果见[运行摘录](evidence/verification.txt)。本次仅运行相关浏览器场景，没有重跑整个历史 E2E 集合。
