# 正式地图与光照

2026-11-01：按用户确认的林岸样板方向并入默认地图，移除独立样板入口、查询参数与存档。保留现有三维人物和建筑，以对话中的森林、沙土路面与蓝色水域图为环境参考。

## 地图与原生实现

- 全图使用固定种子 `20261101`，曲线道路连接家园和外围空地，树木与岩石混合成簇，大小、朝向、间距变化。不是每次新游戏重新随机。
- Babylon 原生 Catmull–Rom 曲线定义湖岸；同一岸线供水面、土地分类、连续碰撞、寻路和建筑禁放使用。道路使用原生二次 Bézier 曲线与连续宽度变化。
- 湖面用原生 ribbon 表现岸边、浅水与深水，配合共享轻量纹理；没有实时反射或额外灯光。
- 草地、林下和路面使用世界尺度色块与共享细节纹理，花草按簇疏密分布，新增耕地与建筑继续清除占地内装饰。
- 树木沿用原生实例化、三档 LOD 和独立阴影 LOD；岩石保留已确认的低面数形体。StandardMaterial 与人物 PBR 材质各自遵循原生颜色流程，不叠加全屏曝光或饱和度滤镜。
- 本次地图资源 ID 和布局变化，使用第 5 版存档，不迁移旧地图进度；浏览器光照与阴影偏好独立保存。

## 可调光照

保持两盏灯：环境半球光 `sky` 与太阳方向光 `sun`。设置可调环境补光、太阳光强度（均为 0–2）及太阳光颜色；默认分别为 0.72、0.56、`#fff4e2`，环境的天空与地面颜色保持方案默认值。

调整更新原生灯光参数，保存浏览器偏好；支持恢复默认与独立阴影开关。设置打开后停止模拟和持续渲染，改变参数只刷新必要画面，不推进作业、成长或人物动作。切后台再返回仍保持暂停，必须点击“继续游戏”。

## 实际画面复现

```sh
VITE_E2E=true npm run build
npm run preview -- --host 127.0.0.1 --port 4175 --strictPort
node scripts/capture-map.mjs
```

脚本使用普通入口与真实镜头操作，支持 `CAPTURE_URL`、`CAPTURE_OUTPUT` 和视角名称参数；输出桌面家园、桌面整体、手机家园、湖岸与全图截图及绘制量 JSON。保留实际界面、人物与材质，没有隐藏 UI 或合成替代画面。

云端 Chromium 使用 SwiftShader，帧率不能代表 iPhone 微信性能；提交面数包含主通道与阴影，随相机、动作、任务和资源变化。真机长时间帧率与发热仍需设备复测。
