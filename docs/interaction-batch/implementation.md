# 建造、自动作业与战斗交互更新

2026-11-04。基于游戏远端 `34c92fc`、设计远端 `99f4407` 完成本批八项修改；提交前再次确认远端没有新增提交。

## 行为与原因

| 项目 | 本批实现 |
| --- | --- |
| 建筑选项 | 原先固定宽 112／128、外层与卡片间隔各 6，手机可见选项少。保留至少 58 CSS 像素高度，宽改为 86、间隔 2、外层内边距 3；完整成本分行显示。393 像素屏幕可完整显示 4 项，保留横滑和拖放。 |
| 建造材料 | 原先 `request()` 忽略预留失败，缺料也创建工地。现在按实际库存减预留判断，在选择、预览和最终放置时校验，缺料选项显示差额并禁用。拒绝不消耗编号、不留占地；完工扣料一次，取消释放预留。 |
| 危险自动任务 | 原先创建任务后才检查完整路线，危险任务进入可见队列。领头现在先检查目标、去程与回仓路线，通过才下单；每次最多规划 8 个候选，受阻候选间隔 2 游戏秒重试。进行中遇险的工作转为后台暂停，保留进度、材料与实物，退出可见列表及计数；共享安全 10 秒后恢复。手动指令持续优先。 |
| 受击反击 | 原先受伤后的索敌仍受距离、营地边界及返程状态限制，近战也会把高处弓兵当成无法攻击的目标。伤害现在独立触发反击，以首次受击位置限定本轮追击范围，后续受击不平移锚点。远程反击塔上弓兵，近战与狼攻击塔身；玩家移动、狼逃跑、袭击到期撤离仍有效。 |
| debug 开局 | 查询参数存在精确键 `debug` 时，新游戏木材／石材／粮食／铁矿各 100,000；调试仓容相应保底。继续游戏不补资源，调试标记及实际消耗随存档保存。 |
| 小地图与提示 | 去掉面板、画布内边距和常驻标题／图例；保留细边框、圆角、无障碍说明及 5 Hz 更新。移除作业队列常驻长说明，建筑／招募状态为空时不占位。设计仓库已加入通用留白与提示取舍规范。 |
| 敌袭人数 | 仅将原有士兵波次人数翻倍，通常 3→6、上限 6→12、弱防守 1→2；狼群、间隔和固定营地行为不变。出生点支持 12 个独立位置，预告和实际出生都检查占用与通路；两位数单位 ID 可保存重载。 |
| 攻击引导 | 原来路线终点是目标外侧的射击接近点，视觉上像未选中敌人。现在同一条路线包含可行走段及目标交互端点；移动仍在原射程、视线和出手预测条件满足时停下，预约、绕障及目标停步预测使用合法接近点。塔顶等目标无需强行走到脚下。每步所有士兵移动后更新目标端点，消除浏览器发现的一个逻辑步滞后。 |

存档升为 v22。按项目约定不迁移旧存档；当前版本保留库存、暂停工作、追击锚点、攻击路径及波次状态。没有改攻击数值、模型、骨骼和动作资源。

## 验证

- 110 个相关逻辑用例：建设预留／拒绝／取消、危险任务预检与恢复、手动指令优先、拆除、建筑生命、塔上战斗、敌我追击移动目标、共享路线、debug 保存、敌袭人数及撤离。后续发现的边界问题修正后复跑对应测试。
- TypeScript 类型检查、生产构建通过。
- 6 个手机 Chromium 场景通过：步兵、骑兵、弓兵分别命中撤退敌人；紧凑建造／缺料禁用／危险队列隐藏／无边距小地图；debug 新开局与继续；共享攻击路线连续移动至停步命中。
- 393×851 与 320×568 界面无横向溢出，卡片高度保留；实际触控放置后，已预留材料不能再次下单。
- 弓兵连续记录 8.35 游戏秒、19 个采样，其中 16 个移动姿态与路径采样。移动速度持续为 4.8，目标端点误差为 0；进入攻击状态后速度归零，目标生命从 65 降至 52.27。录像通过现有编队按钮跟随人物，检查奔跑、停步与出手衔接。
- 额外用种子 1、184、391 检查真实地形上的 12 人入口，均在首轮选点获得合法出生位置；逻辑回归同时检查整波坐标、保存和到期撤离。

主要测试入口：`construction.test.ts`、`economy.test.ts`、`steward.test.ts`、`automatic-work-preflight.test.ts`、`manual-danger.test.ts`、`danger-recovery.test.ts`、`demolition-danger.test.ts`、`combat.test.ts`、`combat-moving-target.test.ts`、`attack-route-retaliation.test.ts`、`raids.test.ts`、`towers.test.ts`、`building-health.test.ts`、`debug-start.test.ts`、`path-guidance.test.ts`。
